# Support

## Supported public surface

TKP Conversation-to-Artifact is a public product component for composing normalized conversation evidence and reviewed authority intelligence into traceable Project Foreman artifacts and a portable package.

For ordinary usage questions and reproducible, non-sensitive defects, use this repository's GitHub Issues.

Please include:

- the sanitized input shape used;
- the command or workflow attempted;
- Python and operating-system versions when relevant;
- the observed result and expected result; and
- a minimal sanitized reproduction when possible.

## Do not post

Do not place private conversation data, credentials, access tokens, client material, local private paths, or sensitive authority records in public issues.

Security- or privacy-sensitive handling follows [SECURITY.md](SECURITY.md).

## Current boundary

Support does not imply raw conversation acquisition, normalization, authority adjudication, execution/completion inference, or general platform/provider portability. Those capabilities are outside this repository's current public contract.
